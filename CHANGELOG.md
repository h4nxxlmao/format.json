# Changelog

## 1.0.0 - 2026-08-26

- Initial release
- JSON formatter with 2 spaces, 4 spaces, and tab indentation
- JSON minifier
- JSON validator with line and column error positions
- Syntax highlighting for keys, strings, numbers, booleans, and null
- File upload and `.json` download
- Clipboard copy with toast notification
- Live character and line counters
- Keyboard shortcuts (`Ctrl+Enter`, `Ctrl+M`, `Ctrl+K`, `Tab`)
- Responsive split and stacked layout
