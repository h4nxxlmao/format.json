# Contributing

Thanks for checking out the project. Contributions and bug fixes are welcome.

## Guidelines

1. **Keep it vanilla**: No build tools, bundlers, npm packages, or external frameworks. Pure HTML, CSS, and JS only.
2. **Offline & private**: The tool must work completely offline without making network requests.
3. **Clean code**: Keep indentation consistent (2 spaces) and ensure code runs without console errors.

## Opening a PR

1. Fork the repo and create your branch: `git checkout -b my-change`
2. Make your changes and test locally by opening `index.html` in a browser.
3. Commit with a clear message: `git commit -m "fix: handle empty string edge case"`
4. Push and open a pull request.
